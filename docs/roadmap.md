# Roadmap

## v0.1

- Project/Paper/Experiment CRUD
- Paper PDF upload and paper-file association through MinIO
- Basic PDF metadata recognition for paper creation
- Zotero-style BibTeX/RIS import for papers
- Experiment repository URL and commit/branch/tag notes
- Weekly report preview, editing, and confirmed save
- Docker Compose
- AI service placeholder

- Richer PDF metadata extraction
- AI paper card generation through configurable OpenAI-compatible API calls
- File management screens
- GitHub commit/branch association
- Better report templates

## v0.3

- Deeper PDF parsing
- Citation-grounded summary
- LangChain/LangGraph workflows

## v0.4

- pgvector-based RAG
- Paper chunk embedding
- Hybrid retrieval
- Experiment-to-paper-claim linking

## v1.0

- Stable open-source release
- Demo data
- Documentation
- Optional user/team support
